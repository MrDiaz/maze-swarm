the rounded UI corners. All borders, title strips, labels, selection
controls, and other menu UI are excluded. Native aspect ratios differ
slightly; use an aspect-preserving fill in Unity rather than stretching.
These are illustrations only: recreate frames and UI as separate layers.

Unity import suggestion: Texture Type Sprite (2D and UI), Sprite Mode
Single, sRGB enabled, Filter Mode Bilinear, Generate Mip Maps disabled
for fixed-scale UI. Use source dimensions; do not upscale source files.
