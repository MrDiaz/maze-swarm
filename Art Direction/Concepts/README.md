## Provenance and scope

Source locations include existing project Concepts and Design folders, current Unity background artwork, the 2026-10-12 and 2026-10-13 task outputs, `/Volumes/T7 Shield/Assets/Objects`, and five original Library references recovered and decoded locally. `manifest.json` and `FILES.csv` list each file, status, original source path, dimensions, SHA256 and known Library identity. Duplicate byte-identical originals are stored once, with other source locations noted in the manifest.

All 13 named light-style screens, four named Hangar alternatives, three supplied Heavy/weapon Library references and ten Cryo object concepts are present. No supplied named concept is unavailable. This is a curated collection rather than a claim to contain every historical generated variation. Production texture maps, individual UI sprites/icons, 3D models, build products, duplicate previews and external-game screenshots are omitted.

Collection is outside Unity Assets so it does not import into the game build. No game source, save, build, phone operation, original artwork or original asset was changed. All 464 recorded game inputs and the preserved 0720 executable hash were checked unchanged.
